# Website Groeipad

Deze repo wordt gevuld door pathweaver-starter. Wijzig hier niets: wijzigingen worden bij de volgende uitrol overschreven.

Wijzigingen aan de site gaan zo:

1. Dien een wens in bij Pathweaver (of werk in de repo pathweaver-starter, map sites/product-website/bron).
2. De starter bouwt en test de wens.
3. Na de PROD-poort (goedkeuring door de eigenaar) rolt de starter de site uit naar deze repo.
